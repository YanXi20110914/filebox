它做的事很少，但都做完了

没有信息流、没有会员、没有推送。只有一条链路：分享 → 归档 → 可查。

01

系统分享直达

任意应用点分享就能唤起，面板里分类已自动选中，点一下即完成。

02

八类自动识别

图片 / 文档 / 视频 / 音频 / 安装包 / 压缩包 / 字体 / 其他，还能加自定义规则。

03

链式防覆盖命名

同名不覆盖：跨年补年份、同年补日期、同日补时分秒。

04

来源记忆

勾一次「记住这个来源」，之后同样的分享静默归档，不再弹窗。

05

十种皮肤

经典白到工作台，布局重排、图标联动、开场动画全套换装。

06

搜索与历史

按名称、分类、来源、时间筛选；支持星标与备注。

07

文本速记

微信里的一段文字，分享过来就存成 .txt，进文档分类。

08

SAF 免权限引擎

不索要「所有文件访问」，只在你指定的目录里工作。

安装

下载 APK 后，系统会提示「允许安装未知应用」，允许即可安装。

系统要求 Android 7.0（API 24）及以上。装过测试签名的设备请先卸载旧版，正式签名无法覆盖安装。

不申请网络权限；拒绝通知权限也能正常使用，只是保存完成时不提醒。
