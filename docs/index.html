安装

下载 APK 后，系统会提示「允许安装未知应用」，允许即可安装。

系统要求 Android 7.0（API 24）及以上。装过测试签名的设备请先卸载旧版，正式签名无法覆盖安装。

不申请网络权限；拒绝通知权限也能正常使用，只是保存完成时不提醒。
