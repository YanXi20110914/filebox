## 三、商店长简介（完整版）

**你的手机文件，值得一间整洁的房间。**

截图、文档、安装包、压缩包……每一次"下载"都在给存储空间添堵。文件收纳盒只做一件事：**让你顺手把文件放对地方**。

**📤 分享即收纳**
在微信、浏览器、文件管理器里点"分享"，选择文件收纳盒——自动识别文件类型，归入对应分类目录（图片/文档/视频/音乐/安装包/压缩包/笔记），全程不超过 3 秒。

**🗂 十种界面皮肤**
经典白、纸张、终端、墨水屏、复古系统、禅意、胶片暗房、霓虹、奶油、工作台——每种皮肤不止换配色：布局重排、桌面图标联动、专属 3D 开场动画，连状态栏都跟着换装。

**📝 文本速记**
微信里看到一段有用的文字？分享给收纳盒，直接存成 .txt 笔记，进"笔记"分类。

**🧠 智能命名防覆盖**
同名文件不覆盖：跨年自动补年份、同年补日期、同日补时分秒——文件再多也永不丢失。

**🔍 全局搜索 + 历史**
按名称、分类、来源、时间筛选所有收纳记录；支持星标与备注，重要文件一眼定位。

**📊 空间统计**
环形图直观展示各分类占用，存储剩余不足 20MB 自动预警，拒绝半截文件。

**🔐 你的文件只属于你**
- 无广告、无开屏、无任何追踪
- 不申请网络权限，物理级完全离线
- 推荐使用系统 SAF 授权（免"所有文件访问"权限），最小权限原则
- 全部数据仅存本机

**⚡ 极致轻量**
安装包 439KB（一张照片的几分之一），运行零后台，不占通知栏常驻，不注册自启。

**适用场景**：收藏图片归类 / 项目文档管理 / 安装包统一存放 / 微信文字收集 / 换机前文件整理 / 强迫症日常急救。

## 五、权限说明（审核与用户透明度）

| 权限 | 用途 | 说明 |
|---|---|---|
| 无 | 网络 | 未申请 INTERNET 权限，应用不可能联网 |
| 通知（可选） | 保存完成提醒 | 拒绝则静默跳过，不影响功能 |
| SAF 目录授权（可选） | 归档目标目录 | 系统级授权，仅限用户指定的目录树 |
| 所有文件访问（可选） | 备用存储引擎 | 不授权则自动使用 SAF，功能完整 |

**本应用不申请**：位置、通讯录、相机、麦克风、电话、短信、安装包列表。
